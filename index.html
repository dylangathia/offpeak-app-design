Task 3: travel destination explorer

Offpeak

Travel applications usually respond to the question "where should I travel." However, in reality, the key question when you plan your trip is when: if the location is open for the season, if any cruise boats are travelling there at the certain time, and if you will pay only half of the price a month later. So the option of month takes the leading position in this app and reorganizes the following app options according to this information.

User flow

Explore→Pick a month→Destination→Shortlist→Compare
Reach→Tap a pin→Destination→Pair it with
Explore→Search / collection→Destination

The rule: teal is the only color that you can use. The colors for the three seasons are determined by data, which indicate what a month is like and are never used for highlighting, buttons, and decorative purposes. A green dot always represents the same meaning irrespective of where it is seen.

Type

  • Fraunces 700/900 for destination names and titles, a soft serif with real warmth, which is what makes the app read as a guidebook rather than a booking engine.
  • Schibsted Grotesk 400/600/700 for all functional text.
  • Scale: 34 / 23 / 21 / 19 / 16 / 14.5 / 13 / 11.5.

On the artwork

Each destination photo is an illustrated piece of vector art made in the American style of banner design from the 1950s. This is because it is essential for an artwork in a portfolio not to be based on someone else's photography and because illustration helps tap into a single visual style of the entire application, which is not possible with stock images.
